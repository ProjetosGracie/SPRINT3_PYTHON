# 🐍 Sprints de Python

Repositório destinado ao desenvolvimento e organização das **Sprints de Python** realizadas durante o curso de **Ciência da Computação na FIAP**.

Os projetos presentes neste repositório têm como objetivo desenvolver, de forma prática, conhecimentos fundamentais de programação, lógica computacional, estruturas de dados, tratamento de erros, modularização e organização de código.

---

## 🎓 Sobre o projeto

Durante as Sprints, são desenvolvidas diferentes soluções utilizando a linguagem **Python**, aplicando conceitos estudados em aula para resolver problemas e construir programas funcionais.

O repositório também representa a evolução dos conhecimentos adquiridos ao longo do curso, desde conceitos básicos da linguagem até a construção de aplicações mais estruturadas.

### Objetivos

* Desenvolver raciocínio lógico e pensamento computacional;
* Aplicar conceitos fundamentais da linguagem Python;
* Praticar estruturas condicionais e de repetição;
* Trabalhar com funções e modularização;
* Utilizar listas, dicionários e outras estruturas de dados;
* Implementar tratamento de exceções;
* Desenvolver programas interativos utilizando menus;
* Organizar projetos de forma clara e estruturada;
* Utilizar Git e GitHub para versionamento dos projetos.

## 🚀 Conteúdos desenvolvidos

Ao longo das Sprints, são trabalhados conceitos importantes para a formação em programação.

### Fundamentos de Python

* Variáveis e tipos de dados;
* Entrada e saída de dados;
* Operadores matemáticos e lógicos;
* Estruturas condicionais;
* Estruturas de repetição;
* Manipulação de strings.

### Funções

Os projetos utilizam funções para dividir o programa em partes menores e facilitar a organização e manutenção do código.

Exemplo:

```python
def calcular_media(valores):
    total = sum(valores)
    return total / len(valores)
```

### Estruturas de dados

Também são utilizados recursos como:

* Listas;
* Tuplas;
* Dicionários;
* Strings;
* Estruturas aninhadas.

Essas estruturas permitem armazenar e manipular os dados utilizados pelas aplicações.

### Tratamento de erros

Alguns projetos utilizam `try` e `except` para tratar entradas inválidas e evitar que o programa seja encerrado inesperadamente.

```python
try:
    opcao = int(input("Escolha uma opção: "))
except ValueError:
    print("Digite apenas números.")
```

### Modularização

Os projetos também trabalham com a divisão do código em funções e módulos, buscando melhorar:

* Organização;
* Legibilidade;
* Reutilização;
* Manutenção do código.

## 💻 Como executar os projetos

### 1. Clone o repositório

```bash
git clone https://github.com/ProjetosGracie/SPRINT3_PYTHON.git
```

### 2. Acesse o diretório

```bash
cd SPRINT3_PYTHON
```

### 3. Execute o arquivo Python desejado

```bash
python nome_do_arquivo.py
```

Em alguns ambientes Linux, pode ser necessário utilizar:

```bash
python3 nome_do_arquivo.py
```
